GetBalances
Retrieve the latest balances for an account.
Supports optional subaccount scoping and returns asset symbols with decimal amounts on REST.

Example
subaccountId
string (fixed64)
Optional sub-account to scope balances to. If omitted, balances are
returned for the authenticated root account derived from the JWT or API
key. The logical account id itself is always derived from the caller's JWT
or API key, not from this payload.
Response
Form
JSON
balances
object[]
One entry for every supported unified asset, including assets with zero
balances. Sorted by available trading amount (highest first), then by
asset symbol alphabetically.
7 fields
assetId
integer (int32)
Public unified asset id. Resolve symbol from SpotConfig; U128 amounts in
this message always use fixed 18-decimal ledger scale.
trading
object
Trading balance at fixed 18-decimal ledger scale.
2 fields
hi
string (fixed64)
Most significant 64 bits.
lo
string (fixed64)

funding

2 fields
hi
string (fixed64)
Most significant 64 bits.
lo
string (fixed64)
Least significant 64 bits.
reserved
object
Reserved amount in the trading bucket at fixed 18-decimal ledger scale.
2 fields
hi
string (fixed64)
Most significant 64 bits.
lo
string (fixed64)
Least significant 64 bits.
available
object
Amount currently available for new trading activity at fixed 18-decimal
ledger scale. This value already accounts for active reservations.
2 fields
hi
string (fixed64)
Most significant 64 bits.
lo
string (fixed64)
Least significant 64 bits.
tradingRevision
string (uint64)
Opaque monotonic revision for the atomic trading, reserved, and available
values. Higher means newer; zero means no trading state has been observed.
fundingRevision
string (uint64)
Opaque monotonic revision for the funding value. Higher means newer; zero
means no funding state has been observed.
