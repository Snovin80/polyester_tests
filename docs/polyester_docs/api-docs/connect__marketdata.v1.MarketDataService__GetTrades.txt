marketdata.v1.MarketDataService
GetTrades
Retrieve recent public trades for a spot market.
Results are ordered newest-first and support optional aggressor side,
inclusive time-range, and opaque keyset pagination filters.

Example
symbolId
integer (int32)
> 0
Stable numeric pair id from GetSpotConfig.
limit
integer (int32)
≤ 1000
Maximum number of trades to return. Defaults to 100 when unset; max 1000.
startTime
string (date-time)
Inclusive lower bound for trade execution time. Must not be more than
5 minutes in the future.
endTime
string (date-time)
Inclusive upper bound for trade execution time. Must be greater than or
equal to start_time when both are set, and must not be more than 5 minutes
in the future.
side
enum
must be defined value
Optional filter by trade aggressor side. Unspecified returns both sides.

string

Opaque keyset cursor from a previous response. The cursor is exclusive and

Response
Form
JSON
trades
object[]
Trades ordered newest-first by execution timestamp, with match_id as a
tie-breaker.
6 fields
symbolId
integer (int32)
Stable numeric pair id from GetSpotConfig.
matchId
string (uint64)
Stable trade id within the symbol, suitable for pagination and de-duplication.
isBuy
boolean
True when the taker/aggressor bought the base asset; false when the
taker/aggressor sold the base asset.
priceTicks
string (int64)
Trade price in quote-asset units scaled by 1e9.
qtyScaled
string (int64)
Traded base-asset quantity scaled by the pair's base_quantity_scale from
GetSpotConfig.
tsNs
string (uint64)
Trade execution timestamp, in nanoseconds since the Unix epoch (UTC).
nextPageToken
string
max 512 chars
Opaque cursor for the next page. Empty when no more results exist.
