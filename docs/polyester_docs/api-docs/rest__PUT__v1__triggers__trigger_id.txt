Example
activationPrice
string
/^[0-9]…9]+)?$/
Updated activation price in quote units scaled by 1e9. Set to zero to clear an existing activation price; omit to leave it unchanged.
limitPrice
string
/^[0-9]…9]+)?$/
Updated limit price in quote units scaled by 1e9 for LIMIT child orders.
maxSlippageBps
integer (int32)
Updated maximum allowed slippage in basis points (1 bp = 0.01%). Set to zero to clear the cap.
maxSlippageTicks
integer (int64)
Non-negative maximum absolute price delta in Q9 execution-price ticks (1 tick = 1e-9 quote units). Set to zero to clear the cap.
subaccountId
string
/^[1-9A…m-z]+$/
Optional sub-account for authorization.
symbol
string
required
Trading pair symbol, e.g. BTC-USDT.
trailingDistanceBps
integer (int32)
required
Updated trailing distance in basis points (1 bp = 0.01%).
trailingDistanceTicks
string
/^[0-9]…9]+)?$/
Updated trailing distance as a price delta in 1e-9 quote-unit ticks.
triggerId
string
required
/^[1-9A…m-z]+$/
Trigger ID to modify.
triggerPrice
string
/^[0-9]…9]+)?$/
Patch fields for safe price, trailing-distance, and slippage edits. For stop/take-profit: Updated trigger price in quote units scaled by 1e9.
