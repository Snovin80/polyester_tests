subaccountId
string (int64)
Optional filter: only keys scoped to this sub-account (opaque ID). The
caller must own or administer the sub-account. If unset, only non-revoked
keys owned by the caller are returned.
Response
Form
JSON
apiKeys
object[]
Matching API keys, newest first. Revoked keys are excluded.
15 fields

Example

string (fixed64)
Optional sub-account this key is scoped to (opaque ID; empty = root-level).
Example
37E2o5r2qHk
policyId
string (fixed64)
Optional API policy attached to this key (opaque ID).
Empty means no policy is attached and the key has no permissions.
Example
3Gxbxht1EK
createdAt
string (date-time)
Time in UTC when this key was created.
Example
2025-01-01T00:00:00Z
lastUsedAt
string (date-time)
Last time in UTC when this key authenticated a request. Omitted when the
key has not been used.
Example
2025-01-01T00:00:00Z
publicKeyEd25519
string (byte)
Ed25519 public key bytes associated with this API key. The private key or
seed is never returned by the API.
Example
AA==
expiresAt
string (date-time)
Optional expiry time in UTC. When set, the key cannot authenticate requests
after this time, regardless of status.
Example
2025-01-01T00:00:00Z
createdByActor
string
Read-only actor label describing who created this key, such as a username
or account label.
Example
dashboard
updatedAt
string (date-time)
Time in UTC when this key's configuration was last changed. For the same
key, later is fresher, equal is an idempotent replay, and earlier is stale.
Equal timestamps with different configuration indicate an invariant failure.
This is independent of last_used_at, which tracks authentication activity.
Example
2025-01-01T00:00:00Z
revision
string (uint64)
Monotonic resource revision used for conditional updates.
Example
1
