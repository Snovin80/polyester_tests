Owner (root account) primary Smart Account address, when available. Allows

subaccountPolicyId
string (fixed64)
Optional sub-account policy identifier (opaque ID). 0 means no
explicit policy attached.
requireMemberMfa
boolean
Owner-controlled security baseline for delegated interactive members on
protected sub-account actions. This does not apply to read-only real-time
subscriptions.
smartAccountSaltNonce
integer (int32)
Smart-account derivation salt nonce assigned when this sub-account was
created. Present only when the caller owns the sub-account and can use it
for direct chain signing.
updatedAt
string (date-time)
Time in UTC when this sub-account's configuration was last changed. For the
same sub-account, later is fresher, equal is an idempotent replay, and
earlier is stale. Equal timestamps with different configuration indicate
an invariant failure.
revision
string (uint64)
Monotonic resource revision used for conditional updates.
totalCreated
integer (int32)
Total number of sub-accounts that have ever been created for this root,
including soft-deleted ones. Request CreateSubaccountChallenge to obtain
the canonical next smart-account address and salt.
