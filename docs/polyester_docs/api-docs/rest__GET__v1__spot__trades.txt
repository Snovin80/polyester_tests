=== ТЕКСТ ===
OrdersService
Get User Trades
Retrieve per-user fills with account-bound keyset pagination. Omit optional filters to list the authenticated account's fills. orderId selects one physical order; lineageId selects the logical order across replacements. These filters are mutually exclusive. throughGeneration requires lineageId. Execution and order-state projections are eventually consistent.
