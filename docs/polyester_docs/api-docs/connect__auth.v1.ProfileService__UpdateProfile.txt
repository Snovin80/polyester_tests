username
string

Public username for the root account. Use an empty string to clear it.
Non-empty values must be 3 to 32 letters, digits, underscores, dots, or
hyphens.
bio
string
bio must be empty or <= 256 characters and must not contain '<' or '>'
Short public bio. Use an empty string to clear it. Non-empty values must be
at most 256 characters and cannot contain "<" or ">".

string

Public website URL. Use an empty string to clear it. Non-empty values must

string

X/Twitter handle without "@". Use an empty string to clear it. Non-empty

string
avatar_url must be empty or a valid http(s) URL
