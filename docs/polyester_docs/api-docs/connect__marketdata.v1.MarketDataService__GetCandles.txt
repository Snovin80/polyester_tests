marketdata.v1.MarketDataService
GetCandles
Retrieve OHLCV candles for a spot market and timeframe.
Results are ordered newest-first and support inclusive time bounds, optional
current open candle inclusion, and optional composite reference candles.

Inclusive lower bound for candle bucket start time, as a UTC timestamp.

endTime
string (date-time)
Inclusive upper bound for candle bucket start time, as a UTC timestamp.
Must be greater than or equal to start_time when both are set, and must not
be more than 5 minutes in the future.
includeIncomplete
boolean
Include the current open candle when it is available and inside the
requested range.
The open candle is prepended to the newest-first candle list and does not
count toward the closed-candle limit.
Unset
False
True
includeReference
boolean
Include the composite reference market candle series for the same market,
timeframe, and time range.
The reference series can be empty when no reference series is available for
the requested timeframe.
