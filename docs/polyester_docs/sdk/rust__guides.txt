Configure trading permissions
After creating a key in the Polyester app, open that key's
Permissions
page:
Enable
Spot trading
Select the markets the bot may trade.
Set the maximum order size and any transfer or withdrawal limits.
Save the policy and confirm it is assigned to the key.
The Rust API-key SDK uses the assigned policy but cannot create or assign one. Policy
administration requires an interactive JWT/session.
Public vs private
Public market data works with no key.
Private RPCs and private WebSocket channels need a key
and
Account ID.

realtime

compatibility flag.

=== ПРИМЕРЫ (дословно) ===

use polyester::{Client, Config};

let client = Client::new(Config {
    environment: Some(polyester::POLYESTER_TESTNET_ENVIRONMENT.clone()),
    api_key_id: Some("ak_...".into()),
    api_private_key: Some("...".into()), // 64-char hex from key creation
    default_account_id: Some("...".into()), // Profile → Account ID
    ..Default::default()
})?;
client.wait_for_catalogs().await?;

---

use std::env;
use polyester::{Client, Config};

let client = Client::new(Config {
    environment: Some(polyester::POLYESTER_TESTNET_ENVIRONMENT.clone()),
    api_key_id: env::var("POLYESTER_API_KEY_ID").ok(),
    api_private_key: env::var("POLYESTER_API_PRIVATE_KEY").ok(),
    default_account_id: env::var("POLYESTER_ACCOUNT_ID").ok(),
    ..Default::default()
})?;
