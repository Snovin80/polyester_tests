The environment keeps API, WebSocket, RPC, and contract pins together.
Config.APIURL
/
Config.WSURL
remain transport overrides. For custom or VPC endpoints, build a complete
environment with
polyester.CreateEnvironment
or
polyester.TestnetEnvironment.WithURLs
Scripts using
polyester.FromEnv()
select the preset with
POLYESTER_ENV=testnet
POLYESTER_API_URL
/
POLYESTER_WS_URL
override the transport URLs.

chain

and account-abstraction endpoints. See
Chain helpers
