Whitelists are enforced allowlists
withdrawal. Re-fetch the relevant view after an invalidation; the event is not a full snapshot.
All calls are authenticated. The invalidation stream additionally requires Account ID and the
address-book read permission. The method returns only after the private token and Centrifugo
handshake succeed.
In shared live fixtures, a denied address-book stream is usually fixture API-key policy, not proof
that the stream or SDK is broken. Verify the key's explicit address-book read permission first.
