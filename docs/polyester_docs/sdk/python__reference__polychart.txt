Methods accept keyword arguments plus raw dict-shaped Protobuf data for layer/drawing identities
and return
ApiData
expected_revision
must use the latest revision from a read.
AUTH_REVISION_CONFLICT
is a state conflict, re-read and reconcile rather than blindly retrying.
Most results are
ApiData
forward-compatible trees.
This collaboration surface is not required for trading and is not a supported production
API-key workflow. It may require JWT/session auth or be unmounted on a deployment. Use the
TypeScript app/session client for interactive chart collaboration.
Keep chart failures isolated from order placement, cancellation, and risk loops.
