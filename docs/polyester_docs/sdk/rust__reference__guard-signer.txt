The action-specific generated requests determine which addresses, chain ID, or whitelist flag is
required. These are authenticated control-plane mutations: do not retry blindly and never log
approval payloads or exported key material.
An approval does not submit an on-chain transaction. Combine it with the matching
Chain helper
and verify the receipt/final state.
