Address-book entries are saved metadata.
Whitelists are enforced allowlists
displaying a destination does not by itself authorize a withdrawal. Re-fetch the relevant view
after an invalidation instead of treating the event as a complete snapshot.
All methods are authenticated. The invalidation channel additionally requires Account ID and the
address-book read permission. In live test accounts, that permission is fixture-policy
configuration, not an intrinsic property of an API-key role; update the fixture policy when the
read is intentionally allowed. The method returns only after the private token and Centrifugo
handshake succeed.
