client.deposit
manages chain deposit addresses. Methods are authenticated.
Deposit addresses are per-account and per-chain. Creating an address is idempotent: it returns the
existing address when one is already assigned. A
deposit flow
can target
funding
or
trading
; select and confirm the intended destination in the corresponding chain flow.
Address creation carries no client-supplied amount or
amount_scale
deposit lifecycle and balance records use canonical ledger
amount_e18
; display precision comes
from asset metadata and must not be confused with the 18-decimal wire scale.

=== ПРИМЕРЫ (дословно) ===

use polyester::proto::chain::deposit::v1::CreateDepositAddressRequest;

let addr = client
    .deposit
    .create_address(CreateDepositAddressRequest {
        chain_id: 1,
        ..Default::default()
    })
    .await?;
println!("{} {}", addr.chain_id, addr.deposit_address);

---

let listed = client.deposit.list_addresses().await?;
for a in &listed.addresses {
    println!("{} {}", a.chain_id, a.deposit_address);
}
