Field
Meaning
Source address
The asset contract on the external chain, or Native when no contract is required.
Zipped Asset
address
The
Polyester Chain
contract for that asset-and-chain route.
Network fee
The fee currently listed for the route.

An estimate based on the route's confirmation requirement.

FAQ
Which assets and networks are supported on Polyester?
p]:my-0 [&_ol]:my-2 [&_ol]:list-decimal [&_ol]:pl-6 [&_p]:my-2 [&_p:first-child]:mt-0 [&_p:last-child]:mb-0 [&_strong]:font-medium [&_strong]:text-foreground [&_ul]:my-2 [&_ul]:list-disc [&_ul]:pl-6 w-full">
Polyester supports most major assets and blockchains for deposits, withdrawals, and trading. Examples include native BTC on Bitcoin, XRP on the XRP Ledger, BCH on Bitcoin Cash, and DOGE on Dogecoin. See the
Supported Assets
table in the user docs for the full list and details for each asset and network.
Can I deposit or withdraw fiat?
p]:my-0 [&_ol]:my-2 [&_ol]:list-decimal [&_ol]:pl-6 [&_p]:my-2 [&_p:first-child]:mt-0 [&_p:last-child]:mb-0 [&_strong]:font-medium [&_strong]:text-foreground [&_ul]:my-2 [&_ul]:list-disc [&_ul]:pl-6 w-full">
No. Polyester does not currently support deposits or withdrawals through banks or cards. For a full list of what you can deposit or withdraw, visit
Supported Assets
in the user docs.
Is there a minimum deposit amount?
p]:my-0 [&_ol]:my-2 [&_ol]:list-decimal [&_ol]:pl-6 [&_p]:my-2 [&_p:first-child]:mt-0 [&_p:last-child]:mb-0 [&_strong]:font-medium [&_strong]:text-foreground [&_ul]:my-2 [&_ul]:list-disc [&_ul]:pl-6 w-full">
Yes. Each asset and network has its own minimum deposit amount. You can see the applicable minimum during the
deposit flow
or find all minimums on the
Supported Assets
page.
Why is a deposit or withdrawal network temporarily unavailable?
p]:my-0 [&_ol]:my-2 [&_ol]:list-decimal [&_ol]:pl-6 [&_p]:my-2 [&_p:first-child]:mt-0 [&_p:last-child]:mb-0 [&_strong]:font-medium [&_strong]:text-foreground [&_ul]:my-2 [&_ul]:list-disc [&_ul]:pl-6 w-full">
A supported network can be temporarily unavailable because of network issues, service pauses, or security checks. Withdrawals also depend on sufficient assets being available on the destination network. You can check Deposit or Withdraw for another supported network that works with your sending or receiving wallet.
Is there a minimum withdrawal amount?
p]:my-0 [&_ol]:my-2 [&_ol]:list-decimal [&_ol]:pl-6 [&_p]:my-2 [&_p:first-child]:mt-0 [&_p:last-child]:mb-0 [&_strong]:font-medium [&_strong]:text-foreground [&_ul]:my-2 [&_ul]:list-disc [&_ul]:pl-6 w-full">
Yes. Each asset and network has its own minimum withdrawal amount. You can see the applicable minimum during the
withdrawal flow
or find all minimums on the
Supported Assets
page.
If one network is paused, can I still trade or use other networks?
p]:my-0 [&_ol]:my-2 [&_ol]:list-decimal [&_ol]:pl-6 [&_p]:my-2 [&_p:first-child]:mt-0 [&_p:last-child]:mb-0 [&_strong]:font-medium [&_strong]:text-foreground [&_ul]:my-2 [&_ul]:list-disc [&_ul]:pl-6 w-full">
A pause affecting one deposit or withdrawal network does not automatically stop trading or other networks. If the trading services remain available, you can continue trading assets already in your
Unified Trading Account
Supported Assets
in the user docs for any asset or network interruptions.
