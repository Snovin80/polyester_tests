## How to read this table
Use **View By Asset** to group routes by asset, or **View By Chain** to see every asset supported on a chain. Expand any row for its route details.
| Field                                  | Meaning                                                                           |
| -------------------------------------- | --------------------------------------------------------------------------------- |
| Source address                         | The asset contract on the external chain, or Native when no contract is required. |
| Zipped Asset address                   | The Polyester Chain contract for that asset-and-chain route.                      |
| Network fee                            | The fee currently listed for the route.                                           |
| Deposit minimum and withdrawal minimum | The smallest listed amount for each action.                                       |
| Confirmations required                 | The minimum number of block confirmations listed for the route.                   |
| Average deposit time                   | An estimate based on the route's confirmation requirement.                        |
Assets with the same symbol are combined only when Polyester maps them to the same Unified Asset.
Timing is an estimate and can vary with chain conditions.
## FAQ
### Which assets and networks are supported on Polyester?
Polyester supports most major assets and blockchains for deposits, withdrawals, and trading. Examples include native BTC on Bitcoin, XRP on the XRP Ledger, BCH on Bitcoin Cash, and DOGE on Dogecoin. See the [Supported Assets](https://testnet.polyester.com/docs/user-docs/funds/supported-assets-and-networks) table in the user docs for the full list and details for each asset and network.
### Can I deposit or withdraw fiat?
No. Polyester does not currently support deposits or withdrawals through banks or cards. For a full list of what you can deposit or withdraw, visit [Supported Assets](https://testnet.polyester.com/docs/user-docs/funds/supported-assets-and-networks) in the user docs.
### Is there a minimum deposit amount?
Yes. Each asset and network has its own minimum deposit amount. You can see the applicable minimum during the deposit flow or find all minimums on the [Supported Assets](https://testnet.polyester.com/docs/user-docs/funds/supported-assets-and-networks) page.
### Why is a deposit or withdrawal network temporarily unavailable?
A supported network can be temporarily unavailable because of network issues, service pauses, or security checks. Withdrawals also depend on sufficient assets being available on the destination network. You can check Deposit or Withdraw for another supported network that works with your sending or receiving wallet.
### Is there a minimum withdrawal amount?
Yes. Each asset and network has its own minimum withdrawal amount. You can see the applicable minimum during the withdrawal flow or find all minimums on the [Supported Assets](https://testnet.polyester.com/docs/user-docs/funds/supported-assets-and-networks) page.
### If one network is paused, can I still trade or use other networks?
A pause affecting one deposit or withdrawal network does not automatically stop trading or other networks. If the trading services remain available, you can continue trading assets already in your Unified Trading Account. Deposits and withdrawals can use other supported networks that are available for the selected asset. Check [Supported Assets](https://testnet.polyester.com/docs/user-docs/funds/supported-assets-and-networks) in the user docs for any asset or network interruptions.
