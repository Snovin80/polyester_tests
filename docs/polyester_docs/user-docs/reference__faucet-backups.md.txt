# Faucet Backups
Use backup faucets when a primary faucet is unavailable. Some require a mainnet balance.
Use these faucets when a [testnet faucet](https://testnet.polyester.com/docs/user-docs/reference/testnet-faucets) is unavailable or rate-limited. Some require a mainnet balance before they will send testnet funds.
After you receive funds, [deposit](https://testnet.polyester.com/docs/user-docs/funds/deposit-assets) them into Polyester.
