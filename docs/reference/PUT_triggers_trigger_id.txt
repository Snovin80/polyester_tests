/^[0-9]…9]+)?$/
Updated activation price in quote units scaled by 1e9. Set to zero to clear an existing activation price; omit to leave it unchanged.

string
/^[0-9]…9]+)?$/
Updated limit price in quote units scaled by 1e9 for LIMIT child orders.
maxSlippageBps
integer (int32)
Updated maximum allowed slippage in basis points (1 bp = 0.01%). Set to zero to clear the cap.
maxSlippageTicks
integer (int64)
Non-negative maximum absolute price delta in Q9 execution-price ticks (1 tick = 1e-9 quote units). Set to zero to clear the cap.

string
/^[1-9A…m-z]+$/

string
/^[0-9]…9]+)?$/

string
